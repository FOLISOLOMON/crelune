## Purpose of this File

This file serves as a root-level discovery pointer for human contributors and AI developer tools that inspect the project root for guidance.

In Google Antigravity, rules located within `.agents/AGENTS.md` are loaded automatically as workspace rules. For other development tools or environments that do not automatically inspect the `.agents/` directory, contributors and agents must refer directly to [`.agents/AGENTS.md`](./.agents/AGENTS.md) for all mandatory engineering standards, architectural guidelines, and non-destructive safety requirements.
